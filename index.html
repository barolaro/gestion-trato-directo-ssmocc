Monitoreo de Trato Directo · Red Asistencial

Metodología del Lineamiento MINSAL v1.0 (jun. 2026). Universo: órdenes aceptadas con recepción conforme, monto neto ítem CLP. Meta 2026: ≤ 16%. Clasificación por establecimiento: Verde ≤ 16% · Amarillo 16–18% · Rojo > 18%. Referencia convenio ADP Subdirección Adm. HFBC: componente TD ≤ 20%.

El semáforo refleja el cálculo automático de la plataforma para el período y universo seleccionados. El plan de trabajo muestra el Anexo N°1 oficial publicado por el administrador (solo lectura); su clasificación puede diferir del semáforo porque el reporte oficial incorpora la variación respecto a 2025. Los establecimientos en Verde no llevan acciones.

Ingrese sus credenciales para administrar los datos de la plataforma.

Nota de seguridad: este acceso protege la interfaz dentro de un archivo estático. No sustituye una autenticación de servidor. Para control centralizado multiusuario, use un backend (p. ej. Streamlit + persistencia GitHub).

Carga masiva de datos (mes a mes)

Suba uno o varios archivos CSV exportados desde Mercado Público, con el mismo formato de columnas (separador «;»). Puede seleccionar múltiples archivos a la vez para alimentar el dashboard de forma masiva; los registros se agregan al conjunto existente y el mes se detecta automáticamente por la fecha de envío.
